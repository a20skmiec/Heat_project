# Heat Project

This project focuses on numerical simulation of heat transfer processes.
It implements mathematical models and computational methods to approximate the evolution of temperature over time.

##  Features

* Numerical solution of heat equation
* Discretization using finite difference methods
* Simulation of temperature distribution
* Visualization of results

##  Technologies

* Python
* NumPy
* Matplotlib

##  How to run

1. Clone the repository:

```bash
git clone https://github.com/a20skmiec/Heat_project.git
cd Heat_project
```

2. Install dependencies:

```bash
pip install numpy matplotlib
```

3. Run the main script:

```bash
python main.py
```

##  Output

The program generates:

* temperature distribution plots
* time evolution of the system

##  Description

The project solves the heat equation using numerical methods.
It demonstrates how physical processes can be modeled and analyzed computationally.
